build:web
anchored
package.json · script

This is the only edge in the repo that is actually wired to something: vercel.json sets buildCommand to `npm run build:web`, so every Vercel deploy executes scripts/build-web.sh under `set -euo pipefail`. The script is not merely an artifact producer — it contains two falsifiable guards whose signal is emitted by the shell, not by the author. (1) `[ -f runs/demo/events.ndjson ] || exit 1` — a filesystem stat in the build sandbox decides it. (2) after the site is assembled it runs `grep -rqF "$secret" web/` for SUPABASE_SERVICE_ROLE_KEY / OPENROUTER_API_KEY / ANTHROPIC_API_KEY, pulled from Vercel project env, and on a hit does `rm -rf web; exit 1`. The developer cannot write the grep result — it is a byte scan of the artifact the build just produced, compared against secrets held outside the repo. A leaked key therefore aborts the deploy. Scope limit worth naming: it asserts absence-of-secret and presence-of-fixture, nothing about whether the app works.

producer bash + coreutils exit status inside the Vercel builder container, running scripts/build-web.sh — actor can write to it: no
